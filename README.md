## Description
A small multi-page site that practises JavaScript fundamentals, DOM manipulation and event handling. Plain HTML, CSS and JavaScript, no libraries.

| Page | Tasks |
| --- | --- |
| `index.html` | Task 0 (first script, console, alert), Task 1 (variables and operators) |
| `dom.html` | Task 2 (change content), Task 3 (change styles), Task 4 (add/remove list items) |
| `events.html` | Task 5 (mouse events), Task 6 (keyboard events), Task 7 (calculator) |
| `todo.html` | Task 8 (to-do app: add, delete, mark as completed) |

Every page has the same navbar. Each page loads its own script (`part1.js` to `part4.js`) and the shared `style.css`.

## How to run
1. Clone or download the repository.
2. Open `index.html` in a browser. Open the console with F12 to see the Task 0 and Task 1 output.

## Deploy (GitHub Pages)
1. Push all files to the repository root.
2. Go to **Settings > Pages**, choose the `main` branch and the `/ (root)` folder, then save.
3. The site is published at `https://plikhk.github.io/<repository-name>/`.
